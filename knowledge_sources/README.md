# 帝显知识库资料清单

本目录保存本次部署使用的中文业务导读和标准适用性导读。资料更新时间为 2026-08-10。

## 知识库规划

1. 帝显公司与业务：公司定位、LED 背光源、TPM 触显全贴合、EMS 电子制造服务。
2. 车载显示与汽车标准：ISO 16750、ISO 26262、UN R10、AEC-Q100、IATF 16949 公开资料。
3. 工业电子与 EMS 制造：PCBA/整机制造、测试、供应链，以及 IPC J-STD-001J、IPC-A-610J 官方公开说明。
4. 质量、环境与医疗体系：ISO 9001、ISO 14001、ISO 13485 与 IATF 16949 的官方公开资料。

## 版权与使用边界

- ISO、IATF 和 IPC 的付费标准正文不从第三方下载，也不上传未授权副本。
- 知识库只导入标准组织公开发布的网页、免费手册、FAQ、勘误/解释文件和公开法规。
- 本目录中的导读为基于官方来源整理的适用性索引，不能替代正式标准、客户特殊要求、合同或认证审核依据。
